The [upstream archive](https://mirrors.mit.edu/CTAN/fonts/ebgaramond.zip) has SHA-256
`853cbacfe4355e851f520946417c91532d756dcaec756002e75648a13c18f769`.

`palette.json` is the installed copy of the reviewed
[Astrivant palette](../../../../docs/assets/brand/pr-palette.json). Update both
together; the Life renderer test enforces equality. Replay fingerprints include
every file in this directory, so asset changes cannot reuse an old rendering claim.
